
# Mini CRM and Quotation System

Web Developer Hiring Challenge 


## Tech Stack

**Client:** React, Tailwind CSS

**Server:** NodeJs, Firebase (Authentication, Firestore and Emulators)


## Environment Variables

To run this project, you will need to add the following environment variables to your .env file

`API_KEY`

`AUTH_DOMAIN`

`PROJECT_ID`

`STORAGE_BUCKET`

`MESSAGING_SENDER_ID`

`APP_ID`

`MEASUREMENT_ID`

## Installation
clone this repository and run the following commands
```bash
  npm install
```

now install the firebase CLI and install needed tools (Authentication, Firestore, Emulators)

to run the project:
```bash
  firebase emulators:start
  npm run dev
```
